DISCOVER — v3 (real photos, realistic globe, travel guide, page-turning book)

INSTALL
1. In your GitHub repo choose Code > Add file > Upload files.
2. Upload index.html, style.css and script.js (not a ZIP) and commit to main.
3. When GitHub Pages finishes, hard-refresh (Ctrl+Shift+R).
Saved Travel Book pages, tasks, wishlist and posts from earlier versions are migrated automatically.

WHAT'S NEW
Photos & backgrounds
- Every photo is now a real photograph from Wikipedia/Wikimedia Commons, matched by exact place name
  (no more wrong Unsplash IDs). If one fails, it falls back to a Wikipedia search, then a gradient.
- The whole page backdrop, the country banner and the challenge card change to a real photo of the
  selected country with a smooth cross-fade. The hero slides through 10 famous places.
Globe
- Starfield sky, ocean specular shine, relief bump, drifting clouds, atmosphere glow.
- Countries stay clear (no cartoon colouring): selected = gold glow, hover = soft highlight,
  visited = mint. A pulse ring marks the country; pins + labels mark its top places and click-scroll
  to the matching card.
Travel guide (new section)
- Best time, suggested stay, budget, getting around; itinerary builder with a trip-length slider
  (2–14 days) and "Copy plan"; must-do list; etiquette, safety and tips; packing + pre-trip
  checklists (ticks are saved); useful phrases.
- Hand-written guides for 13 countries; the other 182 are built live from Wikivoyage + Wikipedia
  (top attractions ranked by real page views).
Moments
- Masonry feed with avatars, locations with flags, hashtags, double-tap heart, comments, save,
  sort (Latest / Popular / Saved / My posts), full-screen photo viewer and a full-screen
  Stories viewer (tap sides, hold to pause, "Explore" jumps to the country).
Travel Book
- A real 3D book: click/tap a page, use the arrows, swipe, or press ← →. Contents page jumps to any
  country; each entry is a polaroid page + handwritten note + "VISITED" stamp; wishlist and
  passport-stats pages; the book opens to your new page (with confetti) when you complete a country.
- On phones it switches to single-page turning.
Transitions
- Loading curtain, scroll progress bar, staggered reveals, cross-faded photos, animated page
  turns, story progress bars, content that rises in when you change country.

NOTES
- Guide text and attraction descriptions for countries without a hand-written guide come in English
  (or French/Spanish/German/Italian when Wikivoyage has that language).
- The 8 "SAMPLE" posts in Moments are placeholders; posts you add are stored only in your own browser.
- Needs internet for the globe, fonts, Wikipedia/Wikivoyage data and photos.
