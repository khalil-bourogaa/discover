DISCOVER — updated cinematic travel experience

INSTALL
1. Open your GitHub repository.
2. Upload/replace index.html, style.css and script.js.
3. Commit to main and wait for GitHub Pages to publish.
4. Hard-refresh the website (Ctrl+Shift+R).

UPDATES IN THIS VERSION
- Tap/click anywhere on the cinematic intro to fade into the site; Skip still works.
- Every country selection shifts the site atmosphere to a matching colour palette.
- Country challenge tasks become destination-aware for the curated country guides.
- Food discovery search is more focused on cuisine and traditional dishes to reduce unrelated results.
- Moments has a clearer community header and improved Instagram-style photo cards, hover states and image fallbacks.
- Travel Book pages have smoother, more tactile 3D page turns with paper-curl shading; swipe, arrows and page controls remain available.

NOTES
- Country photos, destination photos, guide content and the globe require an internet connection.
- Food and attraction information for countries without a hand-written guide is retrieved live from Wikipedia; results can vary by language and availability.
- Posts, likes, saved moments, challenge progress and the Travel Book are stored in this browser.
